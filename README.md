# My Finance OS

## What we are building
A personal finance tracker inspired by modern finance apps.

## Main goals
- Track bank accounts and balances
- Record income and expenses
- Track credit cards and debts
- Record investments and portfolio values
- Calculate total assets, liabilities and net worth
- View monthly spending summaries
- Eventually, ask an AI assistant questions about recorded finances

## Development principles
- Financial calculations must use reliable code, not AI guesses.
- Validate imported and manually entered data.
- Test important calculations.
- Keep passwords and API keys out of the code.
- Start with sample data and local development.

## First version will not include
- Live bank connections
- Automatic payments or transfers
- Automated investment decisions
